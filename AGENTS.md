# Repository instructions

When asked to create a post, use `bin/create-post`.

When adding, changing, or deleting a post, start the subject area in the branch name and commit title with `posts/`. For example, use a branch whose subject area starts with `posts/pg-upgrade` and a commit title such as `[posts/pg-upgrade] ...` to make clear that the change is a post about upgrading Postgres, rather than a Postgres upgrade process for the blog itself.
